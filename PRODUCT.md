# AgentRef Product Context

## Product Register

Product UI. AgentRef is a focused desktop tool where the interface should disappear into the work.

## Users

- Creative professionals and knowledge workers collecting visual references, links, notes, and tasks on an open canvas.
- People working alongside Codex or another agent who need the board's meaning, relationships, and history to remain machine-readable.
- Users who favor very fast capture and spatial thinking over heavyweight project-management workflows.

## Purpose

AgentRef is a local-first infinite reference board for assembling media, web links, notes, and actionable to-do lists in one spatial workspace. It preserves structured context so both the person and their agent can understand what exists, how objects relate, and when task activity happened.

## Brand Personality

Focused, tactile, understated.

## Anti-References

- A Jira-style issue tracker dominated by forms, status machinery, and administration.
- A Notion-style document dashboard that turns the canvas into nested navigation and database chrome.
- A playful whiteboard toy whose decoration obscures precise media and task relationships.
- A social-first collaboration surface crowded with avatars, reactions, and ambient activity.

## Design Principles

1. **Canvas first.** Creation and editing happen in place; permanent panels and modal workflows stay minimal.
2. **Capture before organization.** Adding a task, link, note, or file should take seconds and remain useful without setup.
3. **Relationships stay legible.** Connections should be easy to create, follow, select, and remove without overpowering the referenced media.
4. **Meaning survives persistence.** Structured content, permanent creation timestamps, later state timestamps, and relationships must save cleanly and remain agent-readable.
5. **Reveal power progressively.** Common actions remain obvious while advanced controls appear through selection, focus, or direct manipulation.
6. **Preserve the existing visual language.** Extend AgentRef's monochrome, compact, square-edged system instead of introducing a separate component vocabulary.

## Accessibility

- Target WCAG AA contrast for text and interactive states.
- Provide keyboard-accessible creation, editing, selection, connection deletion, and completion controls.
- Never rely on color alone for status or selection.
- Respect reduced-motion preferences and use motion only to clarify state.
- Keep focus indicators visible and controls comfortably targetable without inflating the board's visual density.
